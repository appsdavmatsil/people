# People

Staff management.

## Run locally

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` if needed, then open [http://localhost:3000](http://localhost:3000).

Production: [https://people-lyart.vercel.app](https://people-lyart.vercel.app).

## Stack

- Next.js + Tailwind
- Supabase Auth and Postgres (`nqvudbhodupyfztgraxw`, ap-northeast-1)
- GitHub: [appsdavmatsil/people](https://github.com/appsdavmatsil/people)
